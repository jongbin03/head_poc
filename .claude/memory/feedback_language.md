# 응답 언어: 한국어

**모든 응답을 한국어로 작성한다.**

**Why**: 사용자가 명시적으로 "한국어로 말해줘"라고 요청함 (2026-07-28).

**How to apply**: 이 프로젝트(`head_poc`)의 모든 대화에서 사용자 메시지의 언어와 무관하게
기본적으로 한국어로 답한다. 코드 주석/커밋 메시지 등 기존에 영어로 되어 있는 부분은 그대로
유지하되(기존 스타일 일치 원칙, [[atlas-poc-code-organization]] 참고), 사용자에게 보여주는
설명/요약 텍스트는 한국어로 작성한다.
